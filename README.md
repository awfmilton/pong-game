# Pong

Classic two-player Pong in a single HTML file.

## Play Online

Play it live: https://pong.kodex.tbay.tk

## Run Locally

Open `index.html` directly in any modern browser. No build step, no dependencies, no server required.

## Controls

| Action | Left player | Right player |
| :--- | :--- | :--- |
| Move up | W | ↑ |
| Move down | S | ↓ |

- **Space** — pause / resume
- **Enter** — start / restart

## Rules

- First player to 7 points wins.
- The ball speeds up slightly on every paddle hit (capped).
- The bounce angle depends on where the ball strikes the paddle — hit near the edge for a sharper return.
